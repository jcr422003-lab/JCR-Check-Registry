# Check Register App

A mobile-friendly check register prototype built with React, TypeScript, and Vite.

## Current features

- Create accounts
- Add transactions
- View balances by account
- Edit and delete transactions
- Search transactions by payee or category
- Filter transactions by account
- Persist data locally in the browser

## Run locally

```bash
cd check-register-app
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
cd check-register-app
npm install
npm run build
```
