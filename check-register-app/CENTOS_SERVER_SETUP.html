CentOS Home Server Setup for the ASUS Laptop

Use this guide to turn the old ASUS laptop into a simple CentOS-based home server for the check register app.

1. Back up and prepare the laptop

1
Back up anything you want to keep from the laptop.
2
Download the latest CentOS Stream ISO from the official CentOS site.
3
Create a bootable USB installer with a tool such as Balena Etcher or Rufus.
4
Boot the ASUS laptop from the USB drive. On many ASUS models, press F2 or Delete to enter BIOS and choose the USB device from the boot menu.
5
If the installer does not boot, try disabling Secure Boot temporarily in BIOS.

2. Install CentOS

1
Choose the Minimal Install option.
2
Set a hostname such as check-home.
3
Create a root password and a non-root administrator account.
4
Make sure networking is enabled during installation.

3. Update the system

sudo dnf update -y
sudo dnf install -y git curl wget nano

4. Install Node.js

curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs
node --version
npm --version

This gives the laptop a current Node.js runtime for the app.

5. Install a process manager

sudo npm install -g pm2

PM2 helps keep the app running after reboots.

6. Clone the app onto the server

cd /opt
sudo git clone https://github.com/jcr422003-lab/JCR-Check-Registry.git
cd /opt/JCR-Check-Registry/check-register-app
npm install
npm run build

7. Run the app on the home network

npm run dev -- --host 0.0.0.0 --port 3000

Then open the laptop’s local IP address from another device on your home Wi-Fi.

hostname -I

Example: http://192.168.1.50:3000

8. Make it start automatically

Create a systemd service so the app comes back after a reboot.

sudo nano /etc/systemd/system/check-register.service
[Unit]
Description=Check Register App
After=network.target

[Service]
WorkingDirectory=/opt/JCR-Check-Registry/check-register-app
ExecStart=/usr/bin/npm run dev -- --host 0.0.0.0 --port 3000
Restart=always
User=your-username
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now check-register.service
sudo systemctl status check-register.service

9. Keep the laptop available

  • Plug the laptop in whenever you want it available all the time.
  • Set power settings to never sleep while plugged in.
  • Keep the Wi-Fi connected to the home network.

10. Optional next step: home-only write access

The app can later be configured so that full write access is allowed only while connected to your trusted home Wi-Fi, and the app becomes read-only or queues changes when you are away.

Note: This setup is intentionally simple and local-first. It keeps the app on your home network and avoids exposing it to the public internet.
